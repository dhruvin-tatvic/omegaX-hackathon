# omegaX-hackathon

Repository for the OmegaX Hackathon projects and assets.

---

## 📂 Repository Contents

- [`sample-website/`](./sample-website): **Apex Moto** — A modern, high-performance React + Vite motorcycle brand website featuring an interactive catalog, test ride booking flow, dealership locator, and responsive dark-theme design.
  - **Live URL:** [https://apex-moto-one.vercel.app](https://apex-moto-one.vercel.app)
  - **Details:** See [`sample-website/README.md`](./sample-website/README.md) for local setup and architecture.

---

## 🚀 Quick Start

To run the sample website locally:

```bash
cd sample-website
npm install
npm run dev
```
